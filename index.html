User Guide · Operational Notes

Voice Settings

Korean and English voices come from the voices exposed by your phone's browser. Available names vary by device and OS. On iPhone, Safari may expose only a limited subset of system voices to websites.

Keep Screen Awake

Enable “Keep Screen Awake” to prevent the display from dimming or locking while this page remains visible. This requires a supported browser and a secure HTTPS connection. The browser or operating system may temporarily release the lock, for example when the page is hidden or under certain power conditions.

Add to Home Screen

On iPhone/iPad, use Safari's Share menu and choose “Add to Home Screen.” When deployed over HTTPS, the app caches its core files so it can still open when the network is unreliable.

Name Translation

Only the “Convert Name to Korean” feature requires internet access and the external MyMemory translation service. The translated result is placed back into the input field so you can adjust the pronunciation before playback. Core announcement and TTS functions remain independent from the translation service.

Progress Display

Word highlighting and the progress bar depend on the device's Web Speech boundary-event support. Speech playback continues independently even when progress events are unavailable.
